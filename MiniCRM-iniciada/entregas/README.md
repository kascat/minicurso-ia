# Pasta de entregas

Descrições de entrega (revisão de código / PR) geradas pela skill `finalizar-tarefa`.

O nome do arquivo é o nome da branch com a barra `/` trocada por traço, incluindo o identificador da tarefa. Exemplo: a branch `T-03-feat/implementacao-formulario-leads` gera `entregas/T-03-feat-implementacao-formulario-leads.md`.
